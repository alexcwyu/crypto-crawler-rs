Updated: 2026-10-12 · Branch: feature/ayu_develop · Source snapshot: f3425a0

Development and layout · Validation evidence · HTML edition

Purpose and scope¶

A multi-crate Rust cryptocurrency market-data toolkit. Venue crawlers combine market discovery, REST snapshots and WebSocket messages, parse exchange payloads and expose normalized message types. It also includes REST clients and a blocking unified HTTP client.

Features¶

  • Independent spot, inverse, linear, option and swap market categories.
  • REST and WebSocket adapters cover multiple exchanges.
  • Callbacks expose streaming messages to consumer applications.
  • Market and symbol utilities support feed setup and filtering.
  • The matching protobuf runtime is pinned for the externally generated crypto-message schema.

Runtime workflow¶

  1. Select venue, market category and subscriptions.
  2. Discover valid symbols and obtain any required snapshots.
  3. Connect to the public WebSocket feed.
  4. Parse and normalize received exchange messages.
  5. Deliver messages to the registered consumer callback.

Current endpoint routing and supplied fixture admission¶

The current OKX client owns separate public/business sockets unless a caller provides an explicit single-endpoint override. The subscription translator preserves the original operation and instrument IDs when partitioning commands. Candles use business; books, tickers and ordinary public channels use public. Both sockets run concurrently and both close during teardown. Binance likewise separates its current linear-futures public and market channels.

    Client->>Public: original operation and books arguments
    Client->>Business: original operation and candle arguments
    par Public feed

    and Business feed
        Business->>Receiver: original candle JSON messages
    end
    Caller->>Client: close
    Client->>Public: close public connection
    Client->>Business: close business connection

Listed-contract fixture support queries actual metadata for the original underlying, settlement family and market type. Quarterly futures remain preferred when the original fixture was quarterly. Options prefer the original strike and then the nearest admitted strike while retaining call/put side. It does not return replay data or drop instruments because a venue no longer lists them. The unchanged supplied assertions still validate real messages. The current funding parser patch maps an omitted optional forecast to None, with upstream license and modification notice.

Coinbase's public Level2 path uses its documented 50 ms batch feed; its Full/Level3 subscription returns an authentication error without account credentials. BitMEX's original futures fixtures are settled. Build/unit success and each dated live integration outcome are separately recorded in validation; neither a current socket acknowledgement nor a substituted market family is counted as a passing original data assertion.
